# Hangman Word Guessing Game

## About
A console-based Hangman game developed using Python.
The player guesses a hidden word one letter at a time.

## Features
- Random word selection from an English word list
- ASCII hangman drawings
- Maximum of 6 incorrect guesses
- Tracks previously guessed letters
- Prevents duplicate guesses from deducting a life
- Victory and defeat messages

## Requirements
- Python 3
- google-10000-english-no-swears.txt

## How to Run
1. Download or clone this repository.
2. Keep hangman.py and the word-list text file in the same folder.
3. Open a terminal in that folder.
4. Run:

   python hangman.py
